### Project Overview

This project explores employee workforce and performance data using SQL to identify patterns in employee satisfaction, salary distribution, overtime, training engagement and departmental performance.
The analysis demonstrates the use of advanced SQL techniques to extract insights from relational datasets and support data-driven workforce decisions.

### Tools

- MySQL
- SQL

### Dataset

The project uses two datasets:

- Employee Dataset: Contains employee demographics, departments, job roles, salaries, overtime and employment information.
- Performance Rating Dataset: Contains employee satisfaction scores, performance ratings, work-life balance and training records.

### SQL Techniques Applied

- JOINs
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (LEAD)
- Views
- Triggers
- CASE Statements
- Aggregate Functions

### Analysis Performed

1. Identified employees working overtime with low job satisfaction or manager ratings.
2. Compared individual salaries against departmental averages.
3. Examined employee hiring sequences across departments.
4. Compared departmental average salaries with the overall company average.
5. Created a trigger to enforce a minimum age requirement during candidate insertion.
6. Created a view to analyse employee training engagement and unused training opportunities.
7. Applied conditional logic to calculate employee salary bonuses.

### Key Findings

- Technology has the largest employee population among the three departments.
- Human Resources records the highest departmental average salary.
- Sales also records an average salary above the overall company average.
- The performance dataset contains multiple review records for individual employees, allowing employee performance to be examined across records.

### Business Recommendations

- Review employee satisfaction and management ratings, particularly among employees working overtime.
- Evaluate departmental compensation structures to support fair and competitive remuneration.
- Improve employee training participation and monitor unused training opportunities.
- Monitor employee performance and satisfaction regularly to support workforce planning.

### Conclusion

This project strengthened my ability to use SQL for data extraction, transformation and analysis. It also demonstrates how relational databases and advanced SQL techniques can be applied to real-world workforce and employee performance analysis.
